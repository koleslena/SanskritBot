# 🕉️ Sanskrit Telegram Bot & API
Универсальный Telegram-бот и изолированный асинхронный API для изучения санскрита, поиска по академическим словарям, транслитерации, анализа словоформ (склонений) и распознавания текста (OCR).

Проект разработан с упором на производительность (используются FastAPI и aiogram 3) и максимальную безопасность данных при развертывании.

## 🚀 Основные возможности
### 1. Перевод по академическим словарям

Бот осуществляет мгновенный поиск по ведущим санскритским словарям:

- MW — Monier-Williams Sanskrit-English Dictionary
- PW — Böhtlingk Sanskrit-Wörterbuch in kürzerer Fassung
- PWG — Böhtlingk and Roth Grosses Petersburger Wörterbuch
- APTE — Apte Practical Sanskrit-English Dictionary
- WIL — Wilson Sanskrit-English Dictionary
- BHS — Edgerton Buddhist Hybrid Sanskrit Dictionary

##### Данные словарей взяты из проекта [COLOGNE](https://github.com/sanskrit-lexicon/COLOGNE)

### 2. Транслитерация текста

Автоматическая конвертация между популярными системами ввода и кодировками:
HK (Harvard-Kyoto) ➡️ Devanagari (Деванагари) ➡️ IAST (Международный алфавит транслитерации санскрита)

### 3. Грамматический анализатор (SHABDA)

Поиск и генерация полных таблиц склонений существительных и спряжений глаголов для точного анализа структуры предложений.

##### Данные взяты из проекта [ashtadhyayi](https://github.com/ashtadhyayi-com/data)

### 4. Тезаурус AMARAKOSHA

Поиск синонимов и концептуальных связей по классическому древнеиндийскому словарю синонимов Амаракоша.

##### Данные взяты из проекта [ashtadhyayi](https://github.com/ashtadhyayi-com/data)

### 5. Распознавание текста (OCR)

Оптическое распознавание символов для графики и фотографий с текстом на Devanagari и автоматический перевод распознанного текста через внутренний API.

## 🛡️ Архитектура безопасности

Проект разворачивается в полностью изолированном сетевом контуре Docker:

- ** Интерфейс API скрыт от внешнего мира:** У сервиса API нет открытых портов наружу (ports). К нему невозможно подключиться из интернета, что исключает прямые атаки на базу данных.
- ** Изолированная сеть:** Бот и API общаются друг с другом внутри замкнутой виртуальной сети Docker по внутренним именам хостов.
- ** Безопасность бота:** Бот работает в режиме Long Polling, сам инициирует запросы к серверам Telegram и не требует входящих открытых портов на сервере.
