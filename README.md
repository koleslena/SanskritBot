# SanskritBot

### Telegram bot for:

* transliterate to or from DEVANAGARI 
    
* translate Sanskrit -> English (MW, APTE, WIL) 
    
* translate Sanskrit -> German (PW, PWG) 
    
* translate Buddhist Hybrid Sanskrit -> English (BHS) 
    
* find synonyms in AMARAKOSHA 
    
* find noun's forms in SHABDA 
    

##### Data from [ashtadhyayi](https://github.com/ashtadhyayi-com/data)
